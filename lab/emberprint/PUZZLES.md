## Technique glossary

Levels are tried cheapest first; each logic round applies every deduction of the cheapest level that finds anything.

| Level | Technique | Meaning |
|---|---|---|
| 0 | Budget exhausted | Every firebreak is already placed, so all remaining cells are open. |
| 0 | Budget fill | Mode B: the unknown cells left exactly match the firebreaks left, so all are firebreaks. |
| 1 | Early-arrival block | Even if every other unknown cell were a firebreak, leaving this cell open lets fire from a source reach a clue too early. It must be a firebreak. |
| 1 | Leak seal | Leaving this cell open lets fire from a source reach a must-never-burn cell no matter what else is blocked. It must be a firebreak. |
| 1 | Lone predecessor | The clue next to this cell cannot ignite on time unless fire passes through this cell, even with every other unknown open. It must be open. |
| 1 | Detour too long | Blocking this cell forces fire onto a detour that reaches a clue too late, even with every other unknown open. It must be open. |
| 1 | Sole corridor | Blocking this cell cuts a clue off from fire completely. It must be open. |
| 2 | Relay block | A clue cell is known to burn by time t, so it acts as a secondary fire source. Fire relayed from it through this cell would reach another clue too early, so this cell must be a firebreak. |
| 2 | Relay leak seal | As Relay block, but the fire relayed from a clue cell would reach a must-never-burn cell. |
| 2 | Held-back front | A clue cell cannot burn before time t, which holds back the fire front passing through it. With that delay, blocking this cell would make another clue ignite too late, so it must be open. |
| 3 | Forced cut | A fire route that reaches a clue too early (or at all, for a never-burn clue) has exactly one unknown cell left on it, after setting aside the cells reserved for other routes. That cell must be a firebreak. |
| 3 | Budget squeeze | Clues need firebreaks on several fire routes that share no unknown cells, and that uses up the whole remaining budget. Each route gets exactly one firebreak, so every cell on none of those routes is open. |
| 3 | Last firebreak | Only one firebreak is left. Putting it on this cell, with everything else open, breaks a clue, so this cell is open. |
| 4 | Shallow contradiction | Assuming the opposite value and propagating the level 0-3 techniques reaches a contradiction (one-step trial and error). |
| 5 | Deep contradiction | Needs a trial whose refutation itself needs nested trials (two-level trial and error). Treated as guessing. |
